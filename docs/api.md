# HTTP API reference

Generated by `tools/gen_api_doc.py` from the route table (`app/api/routes/*`) and `auth.required_permission`. Bodies are JSON unless noted. State-changing calls need the `X-Requested-With: GooyaAsset` header and a valid session cookie. Errors are `{"error": "message"}` with an HTTP status (400 validation, 401 not signed in, 403 no permission, 404, 409 conflict, 500 generic).

A request to any `/api/...` path that is not listed needs the `users.manage` permission (default deny). `PUT /api/settings` is open to any signed-in user at the router level; the handler then requires `backup.manage` for backup keys and `settings.manage` for the rest.
